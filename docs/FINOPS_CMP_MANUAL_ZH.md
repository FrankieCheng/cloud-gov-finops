# GCP 云管与 FinOps 账单飞书机器人 — 使用说明手册

本手册介绍如何使用全新的 **云管与账单飞书机器人** 管理三大核心领域：**MSA 服务公告（`msa/`）**、**Project & Org 双层配额监控（`quota/`）** 与 **BigQuery Export 账单异常分析（`billing/`）**。

---

## 1. MSA 强制服务公告纳管 (`msa/`)

### 核心功能
- **多源导入与脏数据自愈**：支持从 Google Sheet 导出的 `.tsv`/`.csv` 文件直接发进飞书会话完成增量同步，并自动修复原表中因 `429 RESOURCE_EXHAUSTED` 导致的空白/报错建议项。
- **里程碑倒计时分级**：自动识别文本中的所有关键日期，划分为 `🔴 7天内紧急截止`、`🔴 已过节点待核查闭环`、`🟠 30天内临期预警`、`🟡 90天内需排期改造`、`🔵 远期规划` 与 `⚪ 仅通知无需操作`。
- **闭环状态流转**：支持将每条 MSA 标记为 `OPEN` → `IN_PROGRESS` → `MITIGATED`（已解决） / `NOT_APPLICABLE`（不涉及），并记录责任人与受影响项目，重复导入表格不会覆盖人工维护的状态。

### 飞书常用指令
- `查看当前所有待处理的 MSA 服务变更公告`
- `查一下和 Gemini 退役 或 Cloud DNS 相关的 MSA 时间节点`
- `把 Cloud DNS CNAME 这条 MSA 标记为 IN_PROGRESS，责任人 张三，关联项目 demo-shared-dns`
- 直接在飞书对话框向机器人发送最新的 `msa_summary.tsv` 或 `.csv` 文件 → 自动入库并弹出最新 MSA 雷达卡片。

## 2. Project 级 + Organization 级配额监控 (`quota/`)

### 核心功能
- **Project 级全覆盖**：同时采集 Compute Engine 全局与各 Region 资源配额（CPU、GPU、磁盘、IP、VPC、防火墙规则、PSC 转发规则等）以及 Cloud Monitoring `serviceruntime.googleapis.com/quota/*` 各云服务 API 用量与配额上限。
- **Organization 级（组织级）**：采集 `organizations/<ORG_ID>` 下的原生 Cloud Quotas 与组织级配额审批单（`QuotaPreferences`），并对组织下所有关联项目生成跨项目热点配额汇总。
- **三级水位卡片**：自动高亮 **`≥90%` 红线危急配额**与 **`80%–90%` 橙色预警配额**；当全部配额健康（`<80%`）时，展示当前水位最高的前 6 项指标供容量规划参考。

### 飞书常用指令
- `扫描所有项目和组织的 Quota 配额，汇总超过 90% 的风险项`
- `只检查 demo-core-prod 项目的配额使用率（阈值按 80% 看看）`

## 3. Billing Export 每日账单汇总与疑似异常归因 (`billing/`)

### 核心功能
- **精准会计口径（Gross / Credits / Net）**：直连 BigQuery Detailed Billing Export 分区表，同时展示原价（Gross）、折扣抵扣（CUD/SUD/赠金 Credits）与实际净支出（Net），并将 `project.id IS NULL` 的组织级公共支出（CUD 承诺费、Support 订阅费等）单列为 `_BILLING_ACCOUNT_LEVEL_` 杜绝漏算。
- **结算日 (`T-1`) 与今日盘中冲高 (`T-0`) 双轨检测**：默认以昨日完整结算账单作为主口径对比日环比（DoD）与前 7 日滚动基线（Z-Score），避免今日半天账单造成误报；同时实时监测今日盘中未完结账单，一旦半天消费已超昨日全天 125% 立即触发 **盘中实时冲高告警**。
- **多维异常判定与 SKU 级根因下钻**：综合识别**成本突增（Spike）**、**折扣失效导致净支出跳涨（Credit Drop）**、**休眠项目突然产生消费（Dormant Awakening）**，自动选出 **Top-N 疑似问题项目**并下钻列出导致涨跌的前 3 个具体 **Service / SKU / Region**。

### 飞书常用指令
- `汇总昨天的每日各项目账单情况，找出疑似异常波动的项目`
- `回溯分析 2026-11-08 这一天的账单异常，拆解具体是哪个 SKU 涨了`
- `执行一次完整的云管与账单全景巡检`

## 4. 账户管理员高阶治理（预算预测、僵尸浪费回收、SA 密钥审计与 0–100 健康分）

面向企业云账户管理员（Account Admin & CMP Lead）新增四大高阶治理能力：

1. **月末净支出预测（EOM Run-Rate）与综合节省率（ESR）**：
   - 自动结合当月已发生净成本（MTD）与近 7 日加权日均消费预测月末总支出，对比月度预算给出 `HEALTHY / WARNING / EXCEEDED` 评级，并统计当月订阅抵扣与持续使用折扣带来的综合节省率（ESR）。
2. **无标签黑盒成本审计与单实例消费 Top 10**：
   - 自动计算近 7 日未打 `labels / tags` 的黑盒账单占比，并定位消费最高的前 10 个具体云资源实例（如 VM、Cloud SQL、Cloud Run、VPN 隧道）。
3. **实时闲置/僵尸计费资源清查（预计立省 $/月）**：
   - 并发扫描全组织所有项目，识别**保留但未绑定的外部静态 IPv4（$7.30/月/个）**、**未挂载孤儿持久化磁盘**、**已关机仍占盘计费实例**与**超 90 天历史快照**，直接生成 `gcloud` 清理命令参考。
4. **全组织 IAM 与服务账号静态密钥安全卫生（CIS 基线）+ MSA 自动关联真实项目**：
   - 扫描识别**超过 90 天未轮换的静态 SA 私钥**、同一 SA 多把活跃密钥泛滥、顶层公共 IAM 绑定（`allUsers`）以及持有 `roles/editor` / `roles/owner` 的高危默认计算服务账号；
   - 自动根据真实账单活跃服务将每条 MSA 公告精准映射到受影响的具体项目；
   - 汇总输出 **0–100 五维账户治理健康分（评级 A/B/C/D）**。

### 管理员高阶飞书指令示例
- `做一次云账户管理员全景健康评分体检`
- `检查本月预算预测、折扣节省率、无标签黑盒占比以及有哪些闲置浪费资源`
- `分析云架构级固定成本优化机会（VPN、Armor、LB）并排查高消耗 BigQuery SQL 任务执行人`
- `审计全组织超过 90 天未轮换的 SA 静态密钥、高危默认服务账号以及对 0.0.0.0/0 开放的高危防火墙`
- `把 testing-allow-ssh 防火墙告警静默豁免 7 天（原因：测试环境临时联调）`
- `导出修复并关联好项目的最新 MSA 治理台账 TSV`（或在飞书卡片上直接点击 **🔄 跟进 / ✅ 闭环** 按钮原地更新状态）
